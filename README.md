### 👋 About

- Java, Spring Boot, JPA, MySQL로 REST API를 만들어 온 신입 백엔드 개발자입니다.
- 업무 규칙을 코드로 옮기는 설계와 데이터 정합성(소프트 삭제, 유니크 제약, 동시성 제어)에 관심이 있습니다.
- 지금은 팀 프로젝트에서 맡았던 추천·배정 로직을 개인 프로젝트로 다시 설계하고 있습니다.
